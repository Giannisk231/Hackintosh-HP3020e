# Hackintosh-HP3020e
A documentation project about exploring Hackintosh installation on an HP 3020e laptop using OpenCore. This repository contains EFI configuration experiments, boot troubleshooting, compatibility notes, and solutions discovered while attempting to run macOS on non-Apple hardware.
